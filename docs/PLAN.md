# Zespa Review Intelligence 프로젝트 계획

## 목표

한국 주요 쇼핑몰에서 제스파(Zespa) 안마기/마사지기 제품의 공개 리뷰·평점·리뷰수·상품 포지셔닝을 주기적으로 수집하고, 메이저 경쟁사 바디프렌드(Bodyfriend)와 비교하는 자동 업데이트 웹 대시보드를 구축한다.

공식 사이트(`https://www.zespa.co.kr/`) 분석이 아니라, 구매자 접점인 쇼핑몰 리뷰/상품 데이터를 중심으로 브랜드 인식을 조사한다.

## 별도 프로젝트 원칙

- 기존 Tingle/Crack 캐릭터 프로젝트와 완전 분리
- 프로젝트 경로: `/root/projects/zespa-review-intel`
- 독립 git repo 운영
- 데이터/스크립트/대시보드/리포트 모두 이 폴더 아래 저장
- 추후 GitHub repo와 Pages 배포도 별도 운영

## 1차 수집 대상

### 브랜드

- Zespa / 제스파
- Bodyfriend / 바디프랜드 / 바디프렌드 표기 변형 포함

### 제품군 후보

- 목/어깨 마사지기
- 발 마사지기
- 종아리 마사지기
- 허리/등 마사지기
- 마사지건
- 안마의자/프리미엄 안마기
- 온열/공기압/무선 제품군

### 쇼핑몰/채널 우선순위

1. 쿠팡 검색/상품 카드/리뷰 요약
2. 네이버쇼핑 검색 결과/가격비교/리뷰수/평점
3. 11번가, G마켓, 옥션, 오늘의집 등 공개 접근 가능한 범위
4. 필요 시 다나와/에누리 가격비교 보조

## 데이터 수집 범위

### 안정적으로 우선 수집할 지표

- 검색어
- 쇼핑몰
- 브랜드
- 상품명
- 상품 URL
- 가격/할인가
- 평점
- 리뷰수
- 판매자/배송 정보 가능 시
- 랭킹/검색 결과 위치
- 수집 시각(KST)

### 가능하면 수집할 리뷰 지표

- 최신 리뷰 일부 샘플
- 리뷰 별점 분포
- 긍정/부정 키워드
- 반복 불만: 소음, 압박 강도, 내구성, AS, 배송, 사이즈, 가격 대비 성능
- 반복 장점: 시원함, 온열, 가성비, 선물용, 부모님 만족, 사용 편의성

### 주의: 플랫폼 정책/차단 대응

- 로그인/구매자 인증이 필요한 비공개 리뷰는 수집하지 않는다.
- 과도한 대량 크롤링을 피한다.
- robots/이용약관/차단 여부를 존중한다.
- 1일 1회, 검색어별 상위 N개 수준의 저빈도 수집부터 시작한다.
- 쿠팡 등 봇 차단이 강한 플랫폼은 공식/제휴 API 또는 공개 검색결과 중심으로 제한한다.

## 비교 분석 프레임

### Zespa vs Bodyfriend 핵심 비교축

- 가격대: 가성비형 vs 프리미엄형
- 제품군 커버리지: 소형 마사지기 vs 안마의자/헬스케어 대형 제품
- 리뷰량: 브랜드별 리뷰 총량/상위 상품 집중도
- 평점 안정성: 평균 평점, 하위 평점 비율 추정
- 불만 키워드: 내구성/AS/소음/압박/크기/배송
- 만족 키워드: 시원함/온열/부모님 선물/가성비/디자인
- 쇼핑몰별 강세: 쿠팡, 네이버쇼핑 등 채널별 노출/리뷰량

## 산출물

### 데이터

- `data/products.csv`: 상품 단위 최신/이력 데이터
- `data/reviews_sample.csv`: 공개 리뷰 샘플 가능 시
- `data/latest.json`: 대시보드용 최신 요약
- `reports/latest-report.md`: 매일 요약 리포트

### 대시보드

- `public/index.html`
- 브랜드 비교 카드
- 쇼핑몰별 상품 수/리뷰수/평점
- 제품군별 가격대 분포
- 긍정/부정 키워드 랭킹
- Zespa 기회/리스크 인사이트
- Bodyfriend 대비 포지셔닝 요약

### 자동화

- `scripts/collect.py` 또는 `scripts/collect.js`
- `scripts/analyze.py`
- `scripts/update-and-push.sh`
- Hermes cron: 매일 1회 KST 기준 실행

## MVP 구현 순서

1. 공개 검색 수집 가능성 조사
   - 쿠팡/네이버쇼핑에서 검색 결과 HTML/DOM/API 접근 가능성 확인
   - 봇 차단 시 fallback 설계
2. 브랜드/검색어 seed 작성
3. 상위 상품 카드 수집기 구현
4. 가격/평점/리뷰수 normalize
5. 단순 키워드 분석기 구현
6. 정적 대시보드 구현
7. 로컬 검증
8. git commit
9. GitHub repo/Pages 배포
10. Hermes cron 등록

## 성공 기준

- 최소 2개 쇼핑 채널에서 브랜드별 상품 카드 데이터 수집
- Zespa/Bodyfriend 각각 20개 이상 상품 후보 또는 검색 결과 row 확보
- 매일 실행 시 CSV append + latest JSON 갱신
- 대시보드에서 브랜드별 비교가 한눈에 보임
- cron 실행 후 Telegram 또는 웹페이지로 최신 상태 확인 가능
